**FINAL VERDICT: the task is SOLVED — but NOT at the shipped default.** With stock
`bulb_friction=0.01` on every bulb collider (glass included), a parallel-jaw Franka most likely
cannot thread this bulb: the only reachable grip band on a standing bulb is ABOVE the glass equator
(palm-on-dome hard limit), where a μ≈0.01 pinch watermelon-seeds the bulb up and out of the socket
(r3). With the scene's own `bulb_friction` dial at 0.3 (verified physics-neutral for the thread),
the identical strategy solves it cleanly. Recommendation upstream: per-shape friction in bulb.usd
(slick cap SDF, grippable glass) so the default scene is robot-solvable. See README "Scene bugs".
